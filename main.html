Time, Space, Complexity

Time complexity is the measure of how much time an algorithm takes to execute as the input size increases. It helps us understand the performance of an algorithm and determine how efficiently it solves a problem. A lower time complexity generally means a more efficient algorithm.

Space Complexity refers to the amount of memory an algorithm requires to execute. It measures the extra space used by an algorithm depending on the input size. For example, an algorithm that creates an additional array of size n has a Space Complexity of O(n).
